# Principles of Management (AI Plus One)

## About the book

This compact rough draft is for undergraduate or early MBA readers who know basic arithmetic and have not managed a team. Follow a fictional volunteer tool library whose preparation count looks fine while handoffs fall. Learn to define a meaningful outcome, assign decision authority, predict how incentives change behavior, and design a reversible operational trial. No coding or AI account is required.

## Start reading

Begin with [Count the handoff, not just the preparation](chapters/01-count-the-handoff.md), or see the [complete chapter guide](#chapter-guide). Read the Markdown on GitHub or download the repository; no formatted or live web edition is included.

## Chapter guide

### Part I · Design work and accountability

1. [Count the handoff, not just the preparation](chapters/01-count-the-handoff.md): Observe a real result without letting a convenient proxy substitute for it.
2. [Name the owner of the release](chapters/02-name-the-release-owner.md): Separate safety evidence, authority to approve, and accountability for a stalled handoff.
3. [Predict the response to an incentive](chapters/03-predict-the-incentive-response.md): Explain how a sensible person could improve a score while making service worse.

### Part II · Run and revise the operation

4. [Staff the constrained step](chapters/04-staff-the-constrained-step.md): Use supply and stage capacities to bound likely handoffs and diagnose an abnormal shift.
5. [Run a reversible trial](chapters/05-run-a-reversible-trial.md): Set measures, a safety stop, and a continuation rule before observing results.

## How to teach or study it

Work the before/after counts before drawing the process. Once you can name who can release a kit, test an incentive and decide which stage needs help. Finish by defending a reversible change in the [independent turnaround brief](practice/turnaround-review.md), then check your reasoning against the [worked key](practice/turnaround-key.md). The [queue blueprint](https://github.com/nikbearbrown/ai-plus-one-paper/blob/main/book-queue/editorial-blueprints/16-principles-of-management-ai-one.md) is a proposed teaching plan, not an adopted syllabus.
